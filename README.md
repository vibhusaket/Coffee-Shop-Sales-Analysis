# Coffee Shop Sales Analysis Dashboard

## Project Overview

This project presents an interactive Microsoft Excel dashboard developed to analyze coffee shop sales performance. The dashboard transforms raw transactional data into meaningful business insights by tracking key performance indicators (KPIs), sales trends, customer purchasing behavior, and store performance.

---

## Project Objectives

- Analyse overall sales performance across different store locations.
- Monitor key business KPIs using an interactive dashboard.
- Identify peak sales hours and customer purchasing patterns.
- Compare product category performance.
- Enable data-driven business decision-making through dynamic visualizations.

---

## Dataset

The dataset contains **149,000+ sales records** including:

- Transaction Date & Time
- Store Location
- Product Category
- Product Type
- Quantity Sold
- Unit Price
- Total Bill
